## 二、IP 证据五级阶梯：如何辨别真假原生与住宅 IP？

不同第三方 IP 数据库（如 IPinfo、MaxMind、IP2Location）的更新机制各异，经常存在分类冲突。本站建立了 **五级 IP 证据阶梯（IP Evidence Levels）**：

```text
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                五级 IP 证据可信度评估模型 (IP Evidence Levels)                         │
├──────────┬──────────────────────────┬──────────────────────────────────────────────────────────────────┤
│ 证据等级 │ 证据形态与核验来源       │ 本站事实认定原则与可信度说明                                     │
├──────────┼──────────────────────────┼──────────────────────────────────────────────────────────────────┤
│ **E0**   | **未核实 (Unknown)**     | 官网无明确说明，仅节点名称随手写“原生”，**认定为证据不足**       │
│ **E1**   | **官方声明 (Claimed)**   | 官网套餐详情页明确标注原生 IP 或住宅 IP，**认定为‘服务商公开声明’**│
│ **E2**   | **单库匹配 (Single Match)**| 单个数据库（如 IPinfo）显示为本土 ISP 或机房，**仍存在冲突可能** │
│ **E3**   | **多源一致 (Multi-Source)**| **IPinfo、MaxMind、IP2Location 等多个权威库地理与 ASN 均高度一致**│
│ **E4**   | **实测通过 (Target Tested)**| **多源一致且在 2026 年 8 月通过 Netflix 4K 原生解锁与 ChatGPT 实测**│
└──────────┴──────────────────────────┴──────────────────────────────────────────────────────────────────┘
```

## 八、常见问题深度解答（FAQ · 75 问）

### Q1：什么是原生 IP？
**答**：**指 IP 的注册归属地、实际广播地与服务器物理机房所在地完全一致的出口 IP。** 平台检测时不会出现地理冲突，流媒体与 AI 解锁率极高。

### Q2：原生 IP 和广播 IP 有什么区别？
**答**：**原生 IP 地理信息完全匹配，广播 IP 存在注册地与使用地不一致。** 广播 IP 成本较低，但在部分对地区严苛的平台上可能识别异常。

### Q3：原生 IP 和住宅 IP 是一回事吗？
**答**：**不是一回事。** 原生 IP 侧重地理一致性（多数为机房 IP）；住宅 IP 侧重网络属于家庭宽带（ISP）。

### Q4：为什么专线节点不一定是原生 IP？
**答**：**因为专线只负责跨境传输。** 境外落地服务器租用什么类型的 IP 与前端是否走 IEPL 专线完全无关。

### Q5：原生 IP 一定能看 Netflix 吗？
**答**：**绝大多数可以，但非 100% 永久保证。** 流媒体平台会定期封禁被大量滥用的机房 IP 段，需以当前实测为准。

### Q6：静态 IP 和独享 IP 有什么区别？
**答**：**静态指 IP 地址长期固定，独享指该 IP 仅供你一人使用。** 机场的静态节点通常仍是多人共享的。

### Q7：共享 IP 会不会导致我的账号被封？
**答**：**存在一定的邻居行为牵连风险。** 若同节点有用户进行违规滥用，该出口 IP 可能被目标平台临时风控。

### Q8：怎么查一个节点的 ASN 和真实归属？
**答**：**连接节点后访问 `ipinfo.io` 或 `bgp.he.net`。** 查看对应的 ASN 编号及 Organization 信息。

### Q9：为什么不同 IP 查询网站结果会冲突？
**答**：**因为各数据库的更新周期与数据源不同。** 建议参考 IPinfo 与 MaxMind 等多个权威库的交叉比对结果。

### Q10：第一次选原生 IP 机场，最稳妥的建议是什么？
**答**：**选择支持单月付的旗舰专线并实测核心平台。** 验证 ChatGPT 与 Netflix 均能秒开且晚高峰不卡后再长期使用。
