## 一、Clash Verge Rev 到底是什么？架构与角色定位

很多初学者容易将客户端与内核混为一谈。理解 Clash Verge Rev 的底层架构，有助于在遇到故障时快速定位问题所在层级：

```
┌─────────────────────────────────────────────────────────────┐
│ 【桌面图形交互层】 Clash Verge Rev (GUI 前端)                 │
│  职责：提供可视化界面、管理机场订阅 URL、展示节点延迟、提供设置开关 │
└──────────────────────────────┬──────────────────────────────┘
                               │ (调用本地 API 发送控制指令)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 【底层核心驱动层】 Mihomo 代理内核 (Core Engine)               │
│  职责：负责网络数据包加密转发、Layer 3 TUN 虚拟网卡、内置 DNS 与分流规则 │
└─────────────────────────────────────────────────────────────┘
```

### Clash Verge Rev / Mihomo / 订阅源职责分工表

| 组件名称 | 属于什么层级 | 负责的核心工作 | 一旦出现问题时的表现 |
| :--- | :--- | :--- | :--- |
| **Clash Verge Rev** | **桌面客户端 (GUI)** | 窗口渲染、系统托盘管理、订阅文件下载与存储 | 软件界面白屏、托盘图标消失、客户端闪退 |
| **Mihomo Core** | **底层代理内核** | 数据包路由匹配、加密握手、TUN 网卡驱动、内置 DNS | 节点测速报 Timeout、无法建立 TCP 连接 |
| **机场订阅 (Subscription)** | **远程数据源** | 提供服务器 IP/域名、端口、密码、协议类型与策略组 | 节点列表空白、订阅拉取失败、提示 404/过期 |

详细内核原理参考：[《Mihomo 是什么？和 Clash、Clash.Meta 有什么区别？》](/wiki/mihomo-vs-clash/)。

## 三、各操作系统安装与首次启动配置实操

### 1. Windows 系统安装步骤
1. 下载对应的 `_x64-setup.exe` 安装包；
2. 双击运行安装程序，按照提示选择安装路径（建议保持默认）；
3. 安装完成后，在桌面或开始菜单找到 **Clash Verge** 图标点击启动；
4. 首次启动时，Windows Defender 防火墙可能会弹出网络访问提示，**勾选“专用网络”和“公用网络”并点击“允许访问”**。

### 2. macOS 系统安装与权限授予
1. 下载对应芯片架构的 `.dmg` 镜像文件并双击打开；
2. 将 **Clash Verge** 图标拖拽到右侧的 **Applications（应用程序）** 文件夹中；
3. 打开 Launchpad 启动软件。若系统提示 *“无法打开，因为无法验证开发者”*：
   - 打开 Mac **“系统设置” ➔ “隐私与安全性”**；
   - 下滑至“安全性”区域，点击 **“仍要打开”** 即可。

### 3. Linux 系统安装（以 Ubuntu/Debian 为例）
打开终端运行以下命令：
```bash
sudo dpkg -i Clash.Verge_*.deb
# 若缺少依赖项，执行修复：
sudo apt-get install -f
```

## 四、核心实操：导入机场订阅链接与节点激活（图文指南）

安装好客户端后，只需 4 步即可将你购买的机场节点完整加载：

```
① 复制订阅 URL ──> ② Profiles 页面粘贴导入 ──> ③ 单击激活该配置 ──> ④ 代理页面选节点并开代理
```

### 第 1 步：获取机场专属订阅链接
1. 登录你的机场后台（如 [光速云](/reviews/guangsu-cloud/) 或 [微风网络](/reviews/weifeng-cloud/) 用户中心）；
2. 找到“一键订阅”区域，点击 **“复制 Clash 订阅链接”**（URL 通常形如 `https://api.domain.com/api/v1/client/subscribe?token=xxxx`）。

### 第 2 步：在 Profiles 页面导入配置
1. 打开 Clash Verge Rev，在左侧导航栏点击 **“订阅 (Profiles)”**；
2. 在界面顶部的输入框中，长按或右键粘贴刚复制的订阅 URL；
3. 点击输入框右侧的 **“导入 (Import)”** 按钮；
4. 等待 2~5 秒，客户端将向远程服务器请求并下载节点配置。下载成功后，列表中会出现一张展示机场名称与更新时间的卡片。

### 第 3 步：激活选定配置
在订阅卡片列表中，**鼠标左键单击刚导入的配置卡片**。卡片右侧会显示打勾符号或蓝色高亮边框，表示当前客户端已成功加载该配置。

### 第 4 步：选择节点并开启系统代理
1. 点击左侧导航栏的 **“代理 (Proxies)”**；
2. 确认顶部模式处于 **“规则 (Rule)”**；
3. 展开策略组（如 `PROXY` 或 `节点选择`），**手动点击选中一个你喜欢的地区节点**（如香港、日本或新加坡）；
4. 在左侧面板或界面下方，将 **“系统代理 (System Proxy)”** 开关切换为开启（绿色）。

至此，打开浏览器访问 `google.com` 或 `youtube.com`，即可畅快上网！详细订阅原理可参考：[《机场订阅链接怎么导入 Clash？全平台指南》](/tutorials/clash-subscription-import/)。

## 五、分流模式解析：Rule、Global 与 Direct 到底怎么选？

在“代理”页面顶部，你会看到三种不同的运行模式：

```
【Rule 规则分流模式】 (日常推荐 ⭐⭐⭐⭐⭐)
  └─ 智能判断：访问 Google / YouTube 自动走代理，访问 百度 / 淘宝 自动走本地直连，两全其美。

【Global 全局代理模式】 (排查专用 ⭐⭐⭐)
  └─ 强制全部流量（包括国内网站）无条件全部经过选定节点出境，适合排查规则故障或特殊海外业务。

【Direct 直连模式】 (非代理状态 ⭐)
  └─ 所有网络请求完全不经过代理直接裸连，相当于关闭代理功能。
```

> ⚠️ **新手避坑**：日常使用请**务必保持在“Rule 规则模式”**。如果不小心误选了“Direct”，会导致所有国外网站全部打不开。

## 六、系统代理 vs TUN 模式：什么时候才需要开启 TUN？

在 Clash Verge Rev 的设置面板中，有两个非常关键的流量开关：

### 1. 系统代理（System Proxy）
- **工作机制**：修改 Windows/macOS 系统的代理注册表（`127.0.0.1:7897`）；
- **生效场景**：绝大多数浏览器（Chrome/Edge）、网页版 ChatGPT、Telegram 等常规软件；
- **定位**：**90% 普通用户的日常标准配置，系统资源消耗极低、零故障风险。**

### 2. TUN 模式（虚拟网卡模式）
- **工作机制**：在系统网络层创建一张名为 `Mihomo TUN` 的虚拟网卡，强制接管全局所有底层 TCP/UDP 数据包；
- **生效场景**：外服游戏联机、命令行终端（Git Clone / Docker Pull / npm）、部分不遵循系统代理的独立客户端；
- **定位**：**按需开启的高级功能**。

### 系统代理 vs TUN 模式快速对照表

| 对比维度 | 系统代理 (System Proxy) | TUN 模式 (TUN Mode) | 核心选型考量 |
| :--- | :--- | :--- | :--- |
| **工作层级** | 应用层（Application Layer） | 网络层（Layer 3 / IP Layer） | TUN 接管范围更深更全 |
| **UDP 协议支持** | 有限（取决于应用自身） | **原生完整支持** | 游戏连麦、QUIC 必须依赖 TUN |
| **终端命令行支持** | 需手动配置环境变量 | **免配置全局自动生效** | 开发者强烈推荐开启 TUN |
| **新手推荐指数** | ⭐⭐⭐⭐⭐ **(默认首选)** | ⭐⭐⭐ **(按需开启)** | 无特殊需求不建议常开 TUN |

### 如何正确开启 TUN 模式？
1. 点击左侧 **“设置 (Settings)”**；
2. 找到 **“服务模式 (Service Mode)”**，点击右侧的 **“安装 (Install)”** 并在系统弹窗中授权管理员权限；
3. 安装成功后，服务模式会显示为绿色的 `Active`；
4. 此时返回设置面板，将 **“TUN 模式 (TUN Mode)”** 开关打开即可。
详细原理参考：[《Clash TUN 模式和系统代理有什么区别？》](/wiki/clash-tun-mode-vs-system-proxy/)。

## 九、高频疑难故障专项排查手册

### 1. Windows 打开软件出现白屏或闪退
- **原因**：精简版 Windows 系统或第三方封装系统缺少微软 `WebView2` 运行时组件；
- **解决方案**：
  1. 下载安装官方的 `_fixed_webview2-setup.exe` 版本；
  2. 或前往微软官网手动下载安装 *Microsoft Edge WebView2 Evergreen Runtime*。

### 2. 导入订阅后节点列表为空白（数量为 0）
- **原因**：套餐已过期欠费，或订阅被服务商临时限流；
- **解决方案**：登录机场用户中心核对账单状态，右键重新点击“更新订阅”。

### 3. 节点测速显示绿色延迟，但浏览器打不开网页
- **原因**：系统代理未真正写入注册表、杀毒软件拦截端口、或 DNS 解析死锁；
- **解决方案**：参考专文 **[《Clash 有节点但无法上网排查指南》](/issues/clash-connected-no-internet/)** 进行 7 步深度排查。

### 4. 开启 TUN 模式后整台电脑断网
- **原因**：Service 模式未安装、DNS 劫持冲突或同时运行了其他商业 VPN；
- **解决方案**：关闭第三方 VPN，在设置中将 TUN 堆栈切换为 `Mixed`，并临时禁用 IPv6。

## 十、常见故障现象 / 根本原因 / 解决方案速查表

| 故障现象 | 最可能的核心原因 | 优先排查与修复步骤 |
| :--- | :--- | :--- |
| **软件启动白屏/闪退** | 缺少系统 WebView2 组件 | 安装 fixed_webview2 版安装包 |
| **订阅导入提示 Network Error** | 订阅域名被国内宽带拦截 | 用手机 5G 热点导入，或使用机场备用订阅链接 |
| **导入成功但无节点列表** | 套餐到期 / 服务商配置为空 | 登录机场后台核查套餐剩余流量 |
| **有节点有延迟但打不开网页** | 系统代理未开 / 系统时间不同步 | 检查系统代理开关，同步 Windows 系统时间 |
| **一开 TUN 模式立刻全盘断网** | 虚拟网卡路由冲突 / DNS 异常 | 安装服务模式，关闭其他 VPN，切换 TUN 堆栈 |
| **退出软件后电脑无法上网** | 异常退出未清理系统代理 | 重新打开软件正常退出，或在系统设置中关闭手动代理 |

## 十一、高频常见问题解答（FAQ）

### Q1：Clash Verge Rev 和老版 Clash for Windows 有什么区别？
**答**：Clash for Windows 在 2023 年底已经彻底停止维护；Clash Verge Rev 是基于全新 Tauri 框架重构的现代客户端，内置持续更新的 Mihomo 内核，内存占用更小，且完美支持 VLESS-Reality、Hysteria 2 等次世代协议。

### Q2：Windows 应该下载普通版还是 fixed_webview2 版？
**答**：绝大多数正常 Windows 10/11 用户直接下载 **普通版（x64-setup.exe）** 即可。只有当你的电脑启动软件出现白屏报错时，才需要下载 fixed_webview2 版本。

### Q3：为什么节点测速延迟很低，但看 YouTube 依然很慢？
**答**：Ping 延迟只代表向服务器发送小包的响应耗时，不代表持续带宽吞吐。视频卡顿通常是由于底层线路公网拥塞或节点超售。参考：[《机场节点延迟低但速度慢是什么原因？》](/issues/low-ping-slow-speed-reasons/)。

### Q4：Clash Verge Rev 一定要开启 TUN 模式吗？
**答**：**完全不需要。** 普通用户浏览网页、观看流媒体使用系统代理即可。只有在玩外服游戏、终端命令行开发时才建议开启 TUN。

### Q5：更新 Clash Verge Rev 客户端会丢失原有的订阅和配置吗？
**答**：**不会。** 新版本安装包会自动继承系统 AppData 目录下的原有配置文件，直接覆盖安装即可无缝升级。

### Q6：为什么我的订阅链接无法自动定时更新？
**答**：在 Profiles 页面右键点击订阅卡片，选择“编辑 (Edit)”，可以手动设置自动更新间隔（例如设置为 24 小时）。同时确保电脑没有长时间处于睡眠休眠状态。

### Q7：macOS 打开提示“文件已损坏，移至废纸篓”怎么办？
**答**：在 Mac 终端中运行以下命令绕过系统签名拦截：
```bash
sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app
```

### Q8：怎么看客户端的运行日志？
**答**：点击左侧导航栏的 **“日志 (Logs)”**，在顶部选择日志等级（如 `Info` 或 `Error`），即可实时查看内核的连接状态、DNS 解析与报错信息。
