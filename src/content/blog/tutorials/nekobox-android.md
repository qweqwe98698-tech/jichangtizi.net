## 六、第五步：五维闭环验证与出口 IP 检测

连接成功且钥匙图标出现后，必须按照以下五步进行**闭环连通性测试**：

1. **观察 GUI 流量指示**：在 NekoBox 界面观察上传（Up）与下载（Down）实时速率是否有数据跳动；
2. **打开纯净 IP 查询站**：在手机浏览器中打开海外 IP 检测网站（如 `https://ipinfo.io` 或 `https://whoer.net`）；
3. **核验出口归属地**：确认页面显示的 IP 地址与物理国家是否与你选中的代理节点（如日本或美国）一致；
4. **测试核心业务服务**：打开 Google 搜索或 YouTube 4K 视频，确认首屏加载秒开且无缓冲卡顿；
5. **检查国内应用分流**：打开微信或百度，确认国内业务依然走本地宽带直连，未被误代理。

## 八、避坑指南：80 个关于“NekoBox Android 配置”的致命认知误区

```text
❌ 误区 1：在手机上安装好 NekoBox 之后，不需要任何订阅链接就能直接一键翻墙 ➔ 事实：NekoBox 只是管理工具，不包含任何远程代理服务器。
❌ 误区 2：只要手机状态栏出现了 VPN 钥匙图标，就证明外网已经 100% 连通无阻 ➔ 事实：钥匙图标仅代表本地网卡建立，节点超时网页依然打不开。
❌ 误区 3：为了让 NekoBox 达到最高运行速度，手机必须先获取 Root 最高权限 ➔ 事实：NekoBox 基于系统标准的 VpnService 运行，完全不需要 Root。
❌ 误区 4：在 Releases 页面下载 APK 时，文件体积最大的 Universal 一定比 arm64 版更快 ➔ 事实：Universal 是包含所有架构的通用包，运行性能完全相同。
❌ 误区 5：把订阅链接保存进 NekoBox 后，即使不点击更新节点也会自动出现在列表 ➔ 事实：保存 URL 后必须手动或自动执行一次“刷新/更新”拉取。
❌ 误区 6：所有扫描二维码导入的配置都会自动生成包含几十个节点的完整订阅列表 ➔ 事实：若二维码本身是单节点 URI，扫码后列表里只会增加 1 个节点。
❌ 误区 7：在节点列表测速中 Ping 值为 15ms 的节点，看 4K 视频速度一定比 60ms 的节点快 ➔ 事实：Ping 只代表网络往返延迟，不代表线路总下载带宽。
❌ 误区 8：使用 NekoBox 必须把 Android 手机设置里的“私人 DNS（Private DNS）”永久关闭 ➔ 事实：绝大多数系统下可共存，盲目关闭降低本地解析安全。
❌ 误区 9：开启了 TUN 模式后，国内的微信和网银 App 就一定会走海外节点导致异地风控 ➔ 事实：在 Routing 分流规则下，国内流量依然会走本地 Direct 直连。
❌ 误区 10：NekoBox 只要支持 VLESS 和 REALITY，就代表它底层调用了外部的 Xray-core ➔ 事实：sing-box 内核本身原生实现了完整的 VLESS-REALITY 协议。
❌ 误区 11：遇到连接后网页打不开时，第一反应应该是把 NekoBox 卸载并清除全部数据 ➔ 事实：先看日志确认是节点超时还是 DNS 故障，盲目卸载丢失配置。
❌ 误区 12：在分应用代理中勾选了某个 App，该 App 发出的流量就一定会无脑走海外节点 ➔ 事实：勾选仅代表进入 VPN 管道，进入后依然要经过分流规则判定。
❌ 误区 13：只要换用 NekoBox 客户端，就能让原价 5 元/月的慢速直连节点变成企业级专线 ➔ 事实：客户端无法改变物理线路质量，网络性能由机场线路决定。
❌ 误区 14：只要把 NekoBox 的 DNS 设置改成 8.8.8.8，就能彻底解决所有 YouTube 卡顿 ➔ 事实：DNS 仅负责域名解析，不负责为视频传输提供额外物理带宽。
❌ 误区 15：选择日本节点后打开百度依然能正常访问，说明 NekoBox 的节点彻底失效了 ➔ 事实：百度走的是 Direct 本地直连通道，这是分流规则的正确预期行为。
```

## 九、常见问题深度解答（FAQ · 90 问）

### Q1：NekoBox Android 是什么？怎么才能用它上网？
**答**：**NekoBox 是一款 Android 开源代理客户端。** 使用流程：下载安装官方 APK ➔ 导入机场服务商的订阅链接 ➔ 挑选节点 ➔ 授予系统 VPN 权限并启动 ➔ 验证出口 IP 即可上网。

### Q2：下载 NekoBox APK 时，应该选择哪一个文件？
**答**：**绝大多数现代手机选择 `arm64-v8a.apk`。** 若不确定手机芯片架构，可选择兼容性最广的 `universal.apk` 安装。

### Q3：为什么安装时提示“应用未安装”或“签名冲突”？
**答**：**因为手机上已有的旧版本与新 APK 签名证书不一致。** 先备份你的订阅链接，卸载手机上的旧版 NekoBox，再重新安装新下载的官方 APK。

### Q4：NekoBox 需要 Root 权限才能使用吗？
**答**：**完全不需要。** NekoBox 调用 Android 官方的 `VpnService` API 建立虚拟网卡，任何普通未 Root 手机均可完美运行。

### Q5：为什么保存了订阅链接，节点列表里什么都没有？
**答**：**因为保存后尚未执行拉取。** 在分组管理中点击该订阅，选择【更新/刷新】，等待客户端从服务器下载并解析出节点列表。

### Q6：扫码导入和粘贴订阅链接有什么区别？
**答**：**二维码多为单个静态节点，订阅链接通常包含动态节点列表。** 推荐使用订阅链接，节点发生变动时只需一键更新即可同步最新线路。

### Q7：状态栏有 VPN 钥匙图标，但为什么网页还是打不开？
**答**：**钥匙图标仅代表本地 VPN 网卡已启动，不代表远端节点连通。** 查看 NekoBox 日志，检查节点是否超时（Timeout）或 DNS 解析是否异常。

### Q8：为什么选了美国节点，打开国内网站依然显示本地 IP？
**答**：**这是智能分流（Routing）的正常表现。** 国内网站命中了 Direct（直连）规则，走本地物理宽带以保证国内 App 极速且不消耗套餐流量。

### Q9：NekoBox 支持 Hysteria 2 和 VLESS-REALITY 吗？
**答**：**原生完整支持。** 基于现代化 sing-box 内核开发，能够高效承载新一代高性能抗封锁协议。

### Q10：为什么连上 Wi-Fi 能用，切换到 5G 手机网络就断网？
**答**：**通常是移动运营商的 IPv6 路由协商冲突。** 尝试在 NekoBox 中断开并重新连接一次，刷新移动蜂窝网络的路由表。

### Q11：订阅拉取失败或者报 404/Timeout 该怎么排查？
**答**：建议接下来关注本站即将推出的《NekoBox订阅怎么导入？订阅链接、二维码、节点更新与失败完整教程》，系统攻坚订阅层排障。
