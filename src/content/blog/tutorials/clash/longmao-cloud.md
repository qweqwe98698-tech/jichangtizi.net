> **核心结论**：将龙猫云（LongMaoCloud）订阅导入 **[Clash Verge Rev](/tutorials/clash-verge-rev/)** 的标准流程非常简单，全流程仅需 **“复制订阅 ➔ 导入 Profiles ➔ 更新并启用 ➔ Proxies 选节点 ➔ 开启系统代理”** 5 个核心步骤。
> 
> **新手实操铁律**：
> - **第一阶段首要目标**：先让基础网络连通，**千万不要一上来就去修改复杂的 DNS、YAML 覆写、Rule Provider 或强行开启 TUN 虚拟网卡**；
> - **分清两个工具的角色**：龙猫云负责**提供海外节点与订阅数据**，Clash Verge Rev 负责**读取订阅并按规则分流管理流量**；
> - **切记开启系统代理**：打开软件不等于电脑已走代理，必须在主界面打开 **“系统代理 (System Proxy)”** 开关。
> 
> *安全提醒：订阅链接中包含你的专属鉴权密钥 Token，严禁将完整订阅 URL 公开分享到群聊、论坛或上传至不可信的在线转换工具。*

## 一、30 秒极速上手流程图

如果你已经熟悉 Clash 的基本操作，按照以下顺序即可在半分钟内完成配置：

```
[龙猫云后台] 复制专属 Clash 订阅链接 (URL)
     │
     ▼
[Clash Verge Rev] 打开左侧菜单「订阅 (Profiles)」
     │
     ▼

     ▼

     │
     ▼
[开启代理] 返回主界面 ➔ 开启「系统代理 (System Proxy)」开关 ➔ 打开浏览器验证
```

## 二、开始之前需要准备的基础环境

在开始配置前，请确保你已具备以下 6 项基础条件：

1. **一个有效的龙猫云账号**：已注册并处于正常登录状态；
2. **已购买且处于有效期内的套餐**：账户有剩余可用流量，未过期停机；
3. **获取到有效的订阅链接**：支持 Clash / Mihomo 格式的 URL；
4. **已安装好 Clash Verge Rev 客户端**：适用于 Windows 或 macOS 系统的最新稳定版本；
5. **正常的本地网络**：电脑自身可以正常打开国内网页（如百度、B站）；
6. **基础技术角色认知**：
   - **龙猫云** = 提供代理服务器与节点订阅数据；
   - **Clash Verge Rev** = 负责图形化界面展示与配置文件管理；
   - **[Mihomo 内核](/wiki/mihomo-vs-clash/)** = 底层真正负责路由分流、加密传输与 DNS 解析的引擎。

## 三、底层概念辨析：龙猫云订阅链接到底是什么？

很多新手常问：“订阅链接是不是就是一个单独的代理节点？”

**答案是：不是。** 订阅链接是一个**远程配置集合的索引地址（URL）**：

```
                    ┌──────────────────────────────────────────┐
                    │    【龙猫云专属订阅链接 URL (远程托管)】 │
                    └────────────────────┬─────────────────────┘
                                         │ (拉取并解析出完整配置文件)
                                         ▼
            ┌──────────────────────────────────────────────────────────────┐
            │ 包含：节点列表 (香港/日本/美国等) + 加密协议 + 策略组 + 分流规则 │
            └──────────────────────────────────────────────────────────────┘
```

当你把订阅链接填入客户端并点击更新时，Clash Verge Rev 会自动从龙猫云服务器下载包含**节点列表、服务器 IP、端口、加密协议、分流规则组**的完整 YAML 配置文件。

## 四、安全最高铁律：订阅链接千万不要公开泄露！

> 🛡️ **安全操作底线**：
> 1. **订阅链接 = 你的账号提货密码**：订阅 URL 中的参数通常包含专属的 `token` 或 `uuid`，任何拿到你完整链接的人，都可以将你的节点导入到他的设备中；
> 2. **泄露后果**：他人盗刷会导致你的月度流量迅速空仓，甚至触发服务商的“同时在线设备超限”导致账号被封禁；
> 3. **脱敏处理**：在论坛发帖求助或截图交流时，**务必将 Token 参数打码遮蔽**（如 `https://example.com/sub?token=********`）；
> 4. **补救措施**：若怀疑订阅已泄露，请立即登录龙猫云后台找到「重置订阅」或「重新生成链接」，随后在客户端中删除旧配置并重新导入新链接。

## 六、第二步：在 Clash Verge Rev 中导入配置 (Profiles)

1. 打开电脑上的 **Clash Verge Rev** 客户端；
2. 点击左侧导航栏中的 **「订阅 (Profiles)」** 标签页；
3. 在顶部或右上角的 **「订阅 URL」** 输入框中，粘贴刚才复制的龙猫云订阅链接；
4. 在名称栏可以输入自定义备注（例如 `龙猫云-主力`），随后点击右侧的 **「下载 / 导入」** 按钮。

│ ┌───────────────────────────┐                                   │

│ └───────────────────────────┘                                   │

## 七、第三步：更新并激活启用配置（关键避坑点）

这是新手最容易遗漏的步骤：**“下载了配置，不代表已经激活生效！”**

1. **手动更新检查**：右键点击刚才导入的龙猫云配置卡片，选择 **「更新 (Update)」**，确保节点数据已完整拉取到本地；
2. **左键单击卡片设为激活**：直接用鼠标左键单击该配置卡片，当卡片边框高亮显示（或出现对勾图标）时，才代表**该配置已被设置为当前使用的生效 Profile**。

## 八、第四步：进入 Proxies 界面选择节点与运行模式

点击左侧导航栏的 **「代理 (Proxies)」** 菜单：

```
┌────────────────────────────────────────────────────────────┐
│ 1. 运行模式选择: 顶部务必选择【Rule (规则分流)】           │
│ 2. 策略组选择: 展开【PROXY】或【节点选择】卡片              │
│ 3. 选定具体节点: 点击勾选【香港 (HK)】或【日本 (JP)】       │
└────────────────────────────────────────────────────────────┘
```

### 1. 运行模式怎么选？
- **Rule（规则分流 - 强烈推荐）**：系统会智能判断，国内网站（百度、淘宝、微信）走本地直连，国外目标网站（Google、YouTube、ChatGPT）自动走代理，**互不影响，省电省流量**；
- **Global（全局代理）**：所有流量强制走代理，仅在临时排查故障时使用，日常不建议长期开启；
- **Direct（全部直连）**：所有流量不走代理，等同于关闭加速。

### 2. 节点怎么挑？
- **日常查资料 / 办公** ➔ 首选 **香港 (HK)** 节点（低延迟，首屏秒开）；
- **看 4K 视频 / 晚高峰** ➔ 首选 **日本 (JP)** 或 **新加坡 (SG)** 节点（带宽平稳）；
- **ChatGPT / Claude 办公** ➔ 首选 **美国 (US)** 节点（出口纯净度高）。
详细选路技巧参考：[《龙猫云节点有哪些？香港、日本、新加坡、美国节点怎么选》](/reviews/longmao-cloud/nodes/)。

## 九、第五步：开启系统代理 (System Proxy) 并验证连网

回到 Clash Verge Rev 首页（或通过顶部开关）：

1. 将 **「系统代理 (System Proxy)」** 开关切换为 **开启 (ON)** 状态；
2. **打开浏览器验证**：在浏览器地址栏输入 `https://www.google.com` 或 `https://www.youtube.com` 测试能否秒级打开；
3. **查看连接日志**：在 Clash Verge Rev 左侧点击 **「连接 (Connections)」**，若看到有外部请求流量通过你选定的节点正常传输，即代表配置彻底成功！

## 十、进阶认知：什么时候才需要开启 TUN 虚拟网卡模式？

很多新手听说“TUN 模式很强大”，一上来就打开，结果导致电脑网络异常。必须建立理性的技术认知：

```
【普通系统代理 (System Proxy)】 ➔ 拦截浏览器与支持 HTTP 代理的常规软件 (95% 用户日常只需开此项)
【TUN 虚拟网卡模式】            ➔ 在操作系统内核创建虚拟网卡，强制接管所有底层流量与 UDP 协议
```

### 什么时候才需要开启 TUN 模式？
- ❌ **日常浏览网页、查文献、看 YouTube、与 ChatGPT 对话** ➔ **不需要开 TUN**，系统代理已经完美覆盖；
- 🟢 **玩 Steam / 外服游戏需要代理游戏本体的 UDP 联机流量** ➔ **建议开启 TUN**；
- 🟢 **使用 Windows 终端 (CMD / PowerShell / Git Bash) 拉取代码不走代理** ➔ **建议开启 TUN**；
- 🟢 **个别不遵循系统代理设置的专业桌面客户端** ➔ **建议开启 TUN**。
详细机制对比参考：[《Clash TUN 模式和系统代理有什么区别？完整指南》](/wiki/clash-tun-mode-vs-system-proxy/)。

## 十一、核心概念区分：客户端更新 vs 内核更新 vs 订阅更新

| 更新维度 | 实际更新的是什么对象 | 触发场景与操作方式 | 常见注意事项 |
| :--- | :--- | :--- | :--- |
| **订阅更新 (Profile Update)** | **龙猫云的最新节点列表与服务器 IP** | 在 Profiles 卡片右键点击「Update」| **节点连不上或服务商维护后首先执行此项** |
| **内核更新 (Core Update)** | **底层 Mihomo 内核执行程序** | 在客户端设置中的内核管理处在线升级 | 修复底层协议漏洞或适配次世代新加密算法 |
| **客户端更新 (App Update)** | **Clash Verge Rev 软件外壳本身** | 下载新版本安装包覆盖安装 | 优化 UI 界面与交互体验，**更新软件不会丢失已有订阅** |

## 十二、全场景故障排错全景速查表

| 故障现象 | 核心潜在原因 | 优先排查与修复步骤 |
| :--- | :--- | :--- |
| **导入订阅 URL 提示错误 / 报错** | URL 复制不完整、套餐过期停机、网络被拦截 | 重新登录龙猫云后台复制完整链接，确认套餐有剩余流量 |
| **导入成功但 Profiles 里无节点** | 订阅解析格式异常、Profile 未被鼠标单击激活 | 右键 Update 订阅，确保已用鼠标左键单击选中该配置卡片 |
| **所有节点测速全部报红 Timeout** | 本地系统时间未同步、本地裸网异常、订阅过期 | **校准电脑系统时间至秒级精准**，右键更新订阅，检查本地宽带 |
| **有节点能测出延迟，但无法打开网页** | 未开启系统代理开关、DNS 污染、残留旧代理 | **检查主界面「系统代理」是否开启**，重启客户端清理端口占用 |
| **Global 全局可用，但 Rule 规则模式无法上网** | 分流规则文件损坏、Rule Provider 下载受阻 | 在 Profiles 中右键重新 Update 完整配置，重置规则集 |
| **开启 TUN 模式后电脑彻底断网** | TUN 虚拟网卡驱动权限不足、与其他 VPN/网卡冲突 | 以管理员身份运行客户端，关闭其他电脑管家或杀毒软件 |
| **浏览器能上网，但终端/某些软件不走代理** | 该软件不支持读取系统代理环境变量 | 临时为终端配置 `export http_proxy` 或开启 TUN 模式 |

详细排障手册请参考：[《Clash 有节点但无法上网怎么办？7 步系统排查与修复指南》](/issues/clash-connected-no-internet/)。

## 十三、三大高发故障 1 分钟针对性修复指引

### 1. 订阅更新失败或提示 404
- **原因**：服务商可能升级了订阅接口，或你的账户重置了鉴权 Token；
- **解决**：不要在网上乱搜第三方转换，直接登录龙猫云后台重新复制最新的 Clash 订阅链接，粘贴替换即可。

### 2. 节点全部报红 Timeout
- **90% 的根源是系统时间误差**：现代加密协议（如 TLS / Shadowsocks）要求本地时间与服务器误差小于 60 秒。在 Windows 设置中点击“立即同步时间”即可秒级恢复。

### 3. 系统代理开启但网页依然打不开
- **检查浏览器插件**：检查 Chrome / Edge 是否安装了 SwitchyOmega 等代理插件，插件可能会接管并覆盖客户端的系统代理设置，将其设为“系统代理”模式即可。

## 十五、高频常见问题解答（FAQ）

### Q1：龙猫云订阅链接怎么导入 Clash Verge Rev？
**答**：复制龙猫云后台的 Clash 订阅链接，打开 Clash Verge Rev 的 Profiles 页面，粘贴 URL 点击下载，右键更新配置后单击激活，最后在代理页面选好节点并开启系统代理即可。

### Q2：龙猫云订阅导入后为什么 Proxies 页面是空的？
**答**：通常是因为导入后没有右键点击“Update（更新）”，或者没有左键单击该配置卡片将其设为激活状态。确保卡片高亮激活后再次查看 Proxies 页面。

### Q3：为什么节点能测出延迟，但就是打不开 Google？
**答**：最常见的原因是主界面的“系统代理 (System Proxy)”开关没有打开，或者本地电脑时间存在较大偏差导致加密握手失败。

### Q4：Clash Verge Rev 必须开 TUN 模式吗？
**答**：**不需要。** 普通查资料、看视频和日常办公只需开启系统代理即可。仅在外服游戏 UDP 联机或终端命令行拉取代码时才需开启 TUN。

### Q5：龙猫云日常应该选 Rule 还是 Global 模式？
**答**：**强烈建议日常保持 Rule（规则分流）模式**。Rule 模式能让国内网站直连不耗费套餐流量，海外网站自动走代理，两者互不干扰。

### Q6：龙猫云订阅多久需要更新一次？
**答**：平时正常使用无需频繁更新。当发现节点连接卡顿、个别节点失效，或官方发布了机房维护公告后，在 Profiles 卡片上右键执行一次 Update 即可。

### Q7：龙猫云的订阅链接可以借给朋友用吗？
**答**：**不建议。** 订阅链接包含账户完整权限，借给他人会导致你的月度流量被共用消耗，且极易触发设备并发上限导致账号被临时封禁。

### Q8：覆盖安装更新 Clash Verge Rev 会丢失已有订阅吗？
**答**：**不会。** 客户端的配置文件独立保存在用户数据目录下，升级软件版本不会影响已导入的龙猫云订阅。

## 总结与日常维护建议

> **日常顺畅使用 3 大法则**：
>
