## 二、“龙猫云”到底是什么？

为了让第一次接触该服务的新手建立清晰的技术概念，我们简要还原其工作拓扑：

```
[龙猫云服务商] ──(采购服务器与中转机房)──> [生成专属订阅链接 URL]
                                                  │
[目标网站/海外服务] <── [选定具体节点出境] <── [导入本地客户端 (如 Clash)]
```

- **角色定位**：龙猫云属于典型的**代理服务提供方（机场）**，负责在海外机房采购服务器、租用境内外中转链路、部署加密协议并维护节点列表；
- **业务解耦**：龙猫云不是客户端软件，用户在购买套餐后，需要将获得的“订阅链接”导入到 **Clash Verge Rev、FlClash、Shadowrocket** 等独立第三方客户端中配合使用。
详细基础概念科普请参考：[《机场是什么？机场、VPN、梯子、节点和订阅有什么区别？》](/wiki/airport-vs-vpn-difference/)。

## 六、线路架构深度解析：龙猫云是什么线路？

在机场评测中，底层线路架构直接决定了晚高峰时段的稳定性：

```
【公网直连】 用户 ──(公网海缆)──> 海外节点 (成本极低，晚高峰极易受公网拥堵与丢包影响)
      │
      ▼ (进阶中转)
【BGP 隧道中转】 用户 ──> 国内优质机房 ──(专有公网隧道)──> 海外机房出口 (路由优化，延迟可控)
      │
      ▼ (旗舰专线)
【IEPL / IPLC 专线】 用户 ──> 国内入口 ═══(物理内网光缆/不过墙)═══> 海外落地 (晚高峰 0 丢包，极速稳定)
```

### 龙猫云线路客观分析：
1. **中转架构为主**：龙猫云主要采用 **BGP 入口机房配合跨境隧道中转** 架构。相较于低质的公网直连，中转线路能够由服务商优化国内三大运营商（电信、联通、移动）的接入路由，降低网络抖动；
2. **必须建立的理性认知**：
   - **线路名称不等于体验保证**：即使标注了优质中转或专线标签，若服务商在晚高峰遭遇入口带宽超售或突发海缆故障，依然可能产生轻微延迟上升；
   - 实际网络表现不仅取决于服务商服务器，还深度受到**用户本地宽带类型（如北方联通 vs 南方移动）与家庭 Wi-Fi 质量**的影响。
详细线路科普请参考：[《IEPL、IPLC、中转与直连有什么区别？完整指南》](/protocols/iepl-vs-iplc-transit/)。

## 七、节点地区覆盖与分流选型策略

龙猫云的节点布局主要聚焦于中国大陆用户最常访问的核心大区：

```
【亚太核心区】 香港 (HK)、日本 (JP)、新加坡 (SG)、台湾 (TW)、韩国 (KR)
【欧美主力区】 美国 (US)、英国 (UK)、德国 (DE) 等常规机房
```

### 节点选型实战建议：
- **日常网页查资料 / Google / 文献下载** ➔ 优先选择 **香港 (HK) 或 日本 (JP) 节点**（物理距离最近，TCP 握手时延低，网页首屏秒开）；
- **ChatGPT 4o / Claude 3.5 生产力交互** ➔ 优先选择 **美国 (US) 或 台湾 (TW)/新加坡 (SG) 节点**（出口 IP 纯净度相对较高，风控拦截率低）；
- **Netflix / Disney+ 追剧** ➔ 优先选择对应地区的流媒体专用节点（香港节点看中文字幕，美区节点看全量独播内容）；
- **重要原则**：**“有效节点质量远远大于节点总数量”**。拥有 20 个全天候高可用的核心节点，实际体验远胜于堆砌 100 个拥堵不堪的冷门虚假节点。

## 八、协议支持分析：Shadowsocks、VLESS 与 Trojan

龙猫云根据不同的节点与订阅格式，通常支持以下现代代理协议：

| 协议类型 | 核心技术特征 | 适用场景与优势 |
| :--- | :--- | :--- |
| **Shadowsocks (SS / SS-2022)**| 经典轻量级对称加密协议，加解密速度极快 | 配合中转线路使用，客户端 CPU 资源开销极小，省电高效 |
| **Trojan** | 将代理流量伪装成标准合规的 HTTPS 流量 | 伪装特性良好，抗公网阻断能力强，全平台兼容性极佳 |
| **VLESS** | 次世代轻量级无状态协议，去除冗余握手开销 | 搭配现代传输层，转发吞吐高，适配 Mihomo/Clash Verge Rev |

> 📌 **技术分层认知**：**“协议决定数据怎么加密，线路决定数据从哪里走”**。协议名称本身不决定最终网速，核心仍取决于机房的物理带宽承载能力。
> 详细对比参考：[《VLESS、Trojan、Hysteria2 怎么选？2026 协议深度对比》](/protocols/vless-trojan-hysteria2/)。

## 十一、线路与性能表现应该怎么判断？

很多评测喜欢贴一张单次跑出几百兆的测速截图并宣称“全天千兆秒开”，这种宣传并不客观。理性的性能判断逻辑应当包含以下边界：

### 科学评估性能的 4 个核心维度：
1. **单次测速 ≠ 长期稳定性**：上午 10 点测得的极速，不代表晚上 21:00 晚高峰全网拥堵时依然能保持完全一致；
2. **单个节点速度 ≠ 全站所有节点**：热门香港节点可能因并发人数多而速度稍降，切换至负载较低的日本或新加坡节点往往能获得更好体验；
3. **Ping 延迟低 ≠ 下载速度一定快**：Ping 仅代表 ICMP 小包往返耗时，视频播放与大文件下载取决于服务器出口的持续**带宽吞吐与丢包率**；
4. **晚高峰抗压表现是核心**：重点观察晚上 20:00 ~ 23:00 期间看 YouTube 1080P/4K 是否频繁转圈缓冲。
详细排障手册请参考：[《机场节点延迟低但速度慢是什么原因？全面排查指南》](/issues/low-ping-slow-speed-reasons/)。

### Q3：龙猫云是什么线路？是 IEPL 专线吗？
**答**：主要采用优质 BGP 入口机房配合境内外隧道中转架构，部分高阶套餐可能配备优化专线。具体线路承载方式以其实际套餐说明为准。

**答**：**支持。** 在 iPhone 浏览器登录龙猫云后台，点击“一键导入 Shadowrocket”或复制订阅链接至小火箭中添加即可。

### Q7：龙猫云看 YouTube 4K 视频会卡顿吗？
**答**：在平峰时段与带宽充裕的节点上播放 4K 视频体验平稳；在夜间 20:00~23:00 晚高峰期间，建议优先选择负载较低的亚太节点以保证高码率缓冲。

**答**：如果每月流量消耗较快，可在后台升级至更高规格的大流量套餐，或购买不限时流量叠加包补充额度。

### Q9：龙猫云适合多台设备同时使用吗？
**答**：支持在允许的设备并发限制（通常为 2~5 台）内同时使用，满足个人手机、平板与电脑的同时在线需求。

### Q10：龙猫云安全吗？会泄露密码吗？
**答**：在访问 HTTPS 加密网站时，数据在本地已完成强加密，代理服务商无法解密你的明文账号密码。但涉及敏感支付操作时仍建议走本地直连。

### Q11：龙猫云如果遇到节点无法连接怎么办？
**答**：首先在客户端中右键更新订阅配置，检查系统时间是否精准同步，并尝试切换不同地区节点。详细排查步骤请参考：[《Clash 有节点但无法上网排查指南》](/issues/clash-connected-no-internet/)。
