## 三、第二大真相：停更带来的“六层兼容债务”到底是什么？

虽然 NekoBox 不会明天突然暴毙，但随着时间推移，它会逐渐积累**兼容债务（Compatibility Debt）**：

```mermaid
graph TD
    EcoSystem[外部生态持续快速演进] --> Debt1[1. Android 系统层: 新版后台保活策略、VpnService 与通知权限限制]
    EcoSystem --> Debt2[2. 核心内核 Core 层: sing-box 官方内核不断重构, 旧内置 Core 无法享受新优化]
    EcoSystem --> Debt3[3. 传输协议层: 新一代抗封锁协议与加密层参数更替, 旧 Core 无法识别]
    EcoSystem --> Debt4[4. 订阅格式 Schema 层: 机场生成器转向新版 JSON 字段, 导致 Unknown Field 报错]
    EcoSystem --> Debt5[5. 分流规则库层: GeoIP / Geosite 与 Rule Set 规则集格式升级, 旧版解析失败]
    EcoSystem --> Debt6[6. 长期安全维护层: 缺乏官方安全补丁更新, 依赖用户自身的安全防范意识]
```

### 停更兼容债务的典型表现
1. **老节点完全正常，新节点导入报错**：服务商为新节点启用了新协议参数，旧版 NekoBox 报 `Unknown Field`；
2. **升级手机系统后容易掉线**：新版 Android 激进的后台杀进程机制让未经针对性适配的旧版应用更难保活；
3. **复杂规则集加载崩溃**：远程 Rule Set 采用了新版 sing-box 专属二进制格式，旧版无法解析。
