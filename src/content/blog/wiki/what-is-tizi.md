在中文互联网中，“**梯子**”是一个被极其广泛使用的通俗口语词汇。

许多初次接触海外网络访问的新手，往往会被各种名词搞得晕头转向：有人说“下载个 VPN 就是梯子”，有人说“买个机场订阅就能翻墙”，还有人说“装一个 Clash 或 Shadowrocket 小火箭就行了”。甚至有人在电脑上下载了 Clash 软件后，发现根本无法上网，还以为自己遇到了故障。

**“梯子”并不是某一个具体的软件，也不是一种单一的技术协议，更不是一个固定的商业品牌**。

本文旨在作为整个知识库的**认知型基石指南**，用通俗、严谨且中立的语言，彻底拆解梯子、VPN、机场、代理、客户端、节点、订阅链接以及物理线路之间的层级关系，帮助新手建立清晰的技术认知与安全用网逻辑。

## 一、为什么叫“梯子”？概念演变与底层含义

在计算机网络语境中，“梯子”这一词汇具有鲜明的时代特征：

```mermaid
graph LR
    Local[国内本地设备] -- 遭遇网络边界阻断 (直连无法访问) --> Barrier((网络边界 / 访问限制))
    Local -- 搭建虚拟跳板: 客户端 + 中转节点 --> ProxyServer[海外中转代理服务器 (梯子)]
    ProxyServer -- 顺畅跨越边界 --> Target[目标站点: Google / GitHub / OpenAI]
```

1. **形象的比喻**：由于本地网络环境与国际互联网之间存在访问限制（边界），用户无法直接直连海外部分服务，便借助境外的中转服务器作为“跳板”或“梯子”，跨越访问障碍；
2. **它不是官方标准**：在国际电信联盟（ITU）或 IETF 网络标准中，不存在“梯子”这一术语。它纯粹是中文用户的通俗口语；
3. **它不是某个单一 App**：应用商店里没有任何一款正规软件官方命名就叫“梯子”。凡是声称“一键下载万能梯子”的，通常要么是集成了商业 VPN 协议的套壳工具，要么存在恶意软件风险。

## 三、梯子、VPN、机场与代理到底有什么区别？

很多新手最容易纠结的问题就是：“**我到底该用 VPN 还是用机场？它们和梯子到底有什么不同？**”

### 1. 梯子 vs 代理（概念与技术机制）
- **代理（Proxy）**：是一种标准计算机网络协议机制。客户端将自己的 HTTP/SOCKS 请求发送给代理服务器，由代理服务器代为向目标网站请求数据并回传。
- **梯子**：是基于代理或 VPN 技术所构建的**整体网络访问方案的口语称呼**。

### 2. 梯子 vs 商业 VPN（通俗统称与特定产品）
- **传统商业 VPN（Virtual Private Network）**：最初是为企业员工远程安全接入公司内网而设计的虚拟加密隧道（如 OpenVPN、IPsec、WireGuard）。后来被 ExpressVPN、NordVPN 等海外商业公司包装成个人隐私保护工具。
- **典型特征**：官方提供集成的客户端，登录账号后一键连接，通常全局接管所有网络流量。
- **国内使用痛点**：由于传统 VPN 协议特征非常明显，在国内公网环境下极易被骨干网特征识别并精准阻断，导致连接频繁超时、速度慢且价格昂贵。

### 3. 梯子 vs 机场（通俗统称与专属服务商）
- **机场（Airport）**：是中文网络代理社区特有的一类服务提供商。它们采用新一代轻量级、强伪装的代理协议（如 Shadowsocks、VLESS-Reality、Trojan、Hysteria 2），并在国内主要城市部署优质入口，通过 **IEPL / IPLC 跨境物理专线** 将流量转发至海外。
- **典型特征**：服务商不强制绑定闭源 App，而是为用户生成通用的**订阅链接**，用户可自由选择搭配开源强大的第三方客户端（如 Clash、Shadowrocket）。
- **国内使用优势**：**速度快、延迟极低、晚高峰抗拥塞、支持精细的规则分流（访问国内网站不走代理）、性价比极高**。

### 4. 梯子 vs 游戏加速器
- **游戏加速器**（如网易 UU、腾讯加速器）：主要针对特定外服游戏（如 Steam、Epic、战网）的服务器 IP 和 UDP 端口进行专线提速，降低游戏内 Ping 延迟与丢包，**通常无法用于打开 Google 或使用 ChatGPT**。
- **梯子 / 机场**：提供全功能的通用互联网代理，覆盖网页浏览、代码拉取、AI 对话及流媒体视频。

## 五、核心工具辨析：Clash、Mihomo 与 Shadowrocket 到底是不是梯子？

新手最常见的一个认知误区就是把**客户端工具**当成了**梯子服务商**：

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                             客户端 vs 服务商的经典比喻                   │
├──────────────────────────────────────────────────────────────────────────┤
│ 🚗 客户端软件 (Clash / Shadowrocket)  相当于 一辆性能优异的「汽车」      │
│ ⛽ 机场订阅 (Subscription / Nodes)    相当于 汽车赖以行驶的「汽油」      │
│ 🛣️ 跨境专线 (IEPL / IPLC Lines)       相当于 封闭平整的「高速公路」      │
└──────────────────────────────────────────────────────────────────────────┘
```

> ⚠️ **核心结论**：
> 光买了一辆空车（下载了 Clash），里面没有加汽油（未导入订阅链接），汽车是绝对开不走的。同理，光有汽油没有汽车，也无法出行。两者必须组合搭配使用。

### 1. Clash / Clash Verge Rev 到底是什么？
- **Clash** 是由开发者 Dreamacro 原创的开源代理规则引擎；
- **Clash Verge Rev** 是目前 Windows、Mac 和 Linux 上最主流的**现代化开源图形操作界面**；
- 它本身**不提供任何海外节点**，你需要将服务商给你的订阅链接粘贴进去，它才会展示出可用节点列表。
- 实操教程：[《Clash Verge Rev 下载安装与配置完整教程》](/tutorials/clash-verge-rev/) 与 [《什么是 Clash？新手从零开始的系统认知指南》](/wiki/what-is-clash/)。

### 2. Mihomo (Clash.Meta) 是什么？
- **Mihomo** 是目前活跃维护的下一代开源代理核心内核。它接替了原版 Clash 的维护工作，全面支持最新的 **VLESS-Reality、Hysteria 2、TUIC** 协议以及更高级的 DNS 分流机制。Clash Verge Rev 默认即采用 Mihomo 作为核心引擎。
- 深度科普：[《Mihomo 和 Clash 有什么区别？内核演进与核心特性全面解析》](/wiki/mihomo-vs-clash/)。

### 3. Shadowrocket（小火箭）是什么？
- **Shadowrocket** 是 iOS 平台上最著名的第三方付费代理工具 App（售价约 $2.99，需海外 Apple ID 下载）；
- 它同样只是一款**客户端工具**，本身不带节点，导入订阅后即可在 iPhone / iPad 上实现全自动分流代理。
- 实操教程：[《Shadowrocket 小火箭 iOS 订阅配置完整教程》](/tutorials/shadowrocket/longmao-cloud/)。

## 六、新手术语速查词典（14 个高频概念速查）

| 术语名称 | 通俗一句话解释 |
| :--- | :--- |
| **机场 (Airport)** | 专门搭建跨境专线服务器、出售节点订阅服务的商业提供商。 |
| **节点 (Node)** | 位于特定海外机房的一台代理服务器（如香港 01、日本 02）。 |
| **订阅 (Subscription)** | 一条加密的网络配置 URL，客户端通过它可以一键拉取服务商的全部节点信息。 |
| **客户端 (Client)** | 安装在手机或电脑上的代理软件（如 Clash Verge Rev、Shadowrocket）。 |
| **线路 (Line)** | 数据在物理层面传输的通道（如公网直连、BGP 中转、IEPL 物理内网专线）。 |
| **协议 (Protocol)** | 客户端与服务端之间数据加密传输的格式规范（如 SS、VLESS、Trojan、Hysteria 2）。 |
| **倍率 (Rate)** | 流量扣除倍数。1.0x 节点用 1G 扣 1G；0.5x 扣 0.5G；2.0x 专线节点扣 2G。 |
| **系统代理 (System Proxy)** | 客户端修改操作系统层面的网络代理设置，让浏览器等主流软件走代理。 |
| **TUN 模式** | 创建虚拟网卡接管电脑上的所有网络流量，使不遵循系统代理的游戏或命令行也能走代理。 |
| **规则分流 (Rule)** | 客户端根据网址自动判断：访问国内网站（百度/淘宝）走直连，访问国外网站走代理。 |
| **全局代理 (Global)** | 强制所有网络流量无论境内境外一律全部走海外代理服务器。 |
| **直接连接 (Direct)** | 不经过任何代理服务器，本地网络直接访问目标网站。 |
| **DNS 污染** | 本地网络运营商将海外域名的 IP 地址错误解析成虚假 IP，导致网页无法打开。 |
| **重置 Token** | 订阅链接泄露后在服务商后台重置密码密钥，使旧的订阅链接立即失效。 |

## 八、新手到底需要准备什么？两条完全不同的使用路径

对于完全零基础的新手，实现海外网络访问主要有以下两条完全不同的路径：

```mermaid
graph TD
    User[新用户选择路径] --> PathA[路径 A: 机场服务商 + 第三方开源客户端 (主流推荐)]
    User --> PathB[路径 B: 传统商业 VPN 官方 App]

    PathA --> StepA1[1. 挑选一家正规老牌机场 (如光速云/微风网络) 注册并购买单月套餐]
    StepA1 --> StepA2[2. 在用户后台复制「订阅链接 (Subscription URL)」]
    StepA2 --> StepA3[3. 电脑下载 Clash Verge Rev / 手机下载 Shadowrocket]
    StepA3 --> StepA4[4. 将订阅链接导入客户端，点击更新节点]
    StepA4 --> StepA5[5. 选择「香港」或「日本」节点，勾选「System Proxy / 开启连接」]
    StepA5 --> SuccessA[✅ 畅快访问 Google / ChatGPT / YouTube 4K]
```

### 为什么 90% 的国内老用户都选择“路径 A（机场 + 客户端）”？
1. **性价比极高**：主流机场月付仅需 ¥10~20 元，而商业 VPN 动辄每月 ¥50~80 元；
2. **延迟更低更稳定**：机场通常采用定制的 IEPL 物理专线，直连香港延迟仅 30ms，而商业 VPN 往往在 150ms 以上；
3. **智能分流不干扰国内 App**：开启 Clash 规则分流后，访问微信、淘宝、Bilibili 依然走国内高速直连，只有访问海外网站才走代理，完全无需频繁开关。

## 十、梯子安全吗？会泄露密码吗？能不能完全匿名？

许多新手在使用梯子时最大的担忧就是数据安全与隐私问题：

### 1. 梯子服务商能看到我的账号密码吗？
**答：正常情况下看不到。**
目前全球主流网站（Google、ChatGPT、银行、电商等）均强制采用了 **HTTPS (TLS 1.3) 端到端加密**：
- 你的账号密码和通信内容在离开你的浏览器前就已经被加密成密文；
- 代理服务器充当的是**“快递员”**角色，它只能看到你要把包裹送往哪个域名（如 `chatgpt.com`），但**无法拆开包裹解密里面的具体网页内容和密码**；
- ⚠️ **唯一例外**：如果某个不知名的小作坊软件要求你**“在系统里安装一个根证书（Root Certificate）”**，坚决点击拒绝！安装未信任的根证书会导致中间人解密风险。正规机场使用开源客户端绝对不需要安装额外根证书。

### 2. 开启梯子能实现“100% 绝对匿名”吗？
**答：不能。**
代理工具仅仅是改变了你的公网出口 IP 地址。目标网站依然可以通过以下途径识别你的真实身份：
- 你在该网站登录的个人账号；
- 浏览器中留存的 Cookie 与本地缓存；
- **浏览器指纹（Browser Fingerprinting）**：包括你的屏幕分辨率、操作系统字体、Canvas 渲染特征、系统时区与输入法语言。

### 3. 保护你的“订阅链接（Subscription URL）”
订阅链接包含你的个人专属 Token 密钥：
- ❌ **切勿**将订阅 URL 分享给任何人，更不要发布到公开论坛或群聊；
- ❌ **切勿**在不明来历的第三方在线订阅转换网站中直接粘贴完整订阅；
- ⚠️ 一旦怀疑泄露，登录机场后台点击 **“重置订阅信息”** 即可使旧链接失效。

### 4. 梯子是否合法的客观中性提示
不同国家和地区对于网络代理与 VPN 服务的法律监管政策存在明确差异。用户应当自觉遵守所在地的法律法规与单位/学校的网络安全管理规定，合规、文明用网，切勿将代理工具用于任何违法违规活动。

## 十三、常见问题深度解答（FAQ · 25 问）

### Q1：梯子是什么意思？
**答**：在中文互联网语境中，“梯子”是指能够绕过本地网络访问限制、访问海外网站（如 Google、YouTube、GitHub、ChatGPT）的代理网络服务与客户端工具的统称。

### Q2：为什么叫梯子？
**答**：因为网络限制就像一道无形的“墙”，用户借助境外的中转代理服务器作为跳板跨越障碍，形象地称之为“搭梯子”。

### Q3：梯子工具和梯子软件是什么？
**答**：指安装在手机或电脑上的代理客户端软件（如 Clash Verge Rev、Shadowrocket、v2rayN、Sing-box 等），它们负责将你的网络流量加密转发给海外服务器。

### Q4：梯子有什么作用？能做什么？
**答**：主要用于日常查阅国际学术文献、使用 ChatGPT/Claude 等 AI 工具、进行 GitHub 代码开发协作、观看 YouTube 4K 超高清视频以及开展外贸跨境电商业务。

### Q5：梯子可以访问什么网站？
**答**：包括但不限于 Google、YouTube、GitHub、OpenAI (ChatGPT)、Claude、Twitter (X)、Telegram、Wikipedia、Netflix、Disney+ 等国际网站。

### Q6：VPN 是不是梯子？
**答**：在广义口语中，很多人把 VPN 称为梯子；但从技术上讲，VPN 是一种虚拟加密隧道技术，只是众多海外网络访问方案中的一种。

### Q7：机场是不是梯子？
**答**：是的。在目前的国内网络环境下，“机场（专线代理服务商）+ 开源客户端”是绝大多数用户最主流、性价比最高且最流畅的梯子形态。

### Q8：Clash 是不是梯子？
**答**：**Clash 本身不是梯子服务商，而是一个开源代理客户端。** 下载 Clash 后必须导入机场提供的**订阅链接**才能正常上网。

### Q9：Shadowrocket（小火箭）是不是梯子？
**答**：**不是。** Shadowrocket 是苹果 iOS 平台上的第三方代理工具 App，本身不自带任何节点，需要配合机场订阅使用。

### Q10：节点是什么意思？
**答**：节点指服务商部署在香港、日本、美国等各个国家机房的具体代理服务器。你在客户端中选择“日本 01 节点”，你的网络出口 IP 就会显示在日本。

### Q11：订阅链接是什么？
**答**：是一串由服务商生成的加密网络链接（URL）。客户端通过该链接可以自动同步并下载服务商提供的所有节点名称、服务器地址和加密密钥。

### Q12：机场和 VPN 哪个好？
**答**：对于绝大多数国内用户，**机场 + 客户端在速度、稳定性、智能分流（国内网站不减速）以及性价比上远优于传统商业 VPN**；传统 VPN 仅在海外或特定企业内网环境下具有通用性。

### Q13：手机怎么使用梯子？
**答**：iPhone 用户在海外 App Store 下载 **Shadowrocket（小火箭）** 并导入机场订阅；Android 用户下载 **Clash Meta for Android** 或 v2rayNG 导入订阅。

### Q14：电脑怎么使用梯子？
**答**：Windows 与 Mac 电脑推荐下载开源软件 **Clash Verge Rev**，在配置中粘贴机场订阅链接，选择节点并开启「系统代理」即可。

### Q15：梯子需要花钱买吗？
**答**：是的。虽然存在少数免费体验包，但海外服务器与跨境专线带宽每月都需要高昂的物理租金，因此稳定、高速的日常用网通常需要购买付费机场套餐（约 ¥7~20 / 月）。

### Q16：有永久免费的梯子吗？
**答**：**不存在真正长期高速的永久免费梯子。** 所谓的免费工具往往伴随着严重的限速、广告轰炸、节点频繁失效甚至收集转售用户隐私数据的隐形成本。

### Q17：梯子安全吗？会泄露密码吗？
**答**：访问主流 HTTPS 网站时，密码在浏览器端已经经过端到端高强度加密，代理服务器无法解密你的明文密码。只要不安装可疑的第三方根证书，数据传输是安全的。

### Q18：使用梯子能做到完全匿名吗？
**答**：不能。梯子仅改变了网络出口 IP，目标网站依然可以通过登录账号、本地 Cookie、浏览器指纹以及语言时区识别用户。

### Q19：订阅链接泄露了怎么办？
**答**：立即登录机场后台，在用户中心点击 **“重置订阅信息 / 重置 Token”**，旧的订阅链接就会立刻失效。

### Q20：为什么节点很多但都显示 Timeout 超时？
**答**：通常是因为本地电脑系统时间存在偏差导致 TLS 握手失败，或者客户端保存了过期的服务器 IP。在系统设置中同步北京时间并在客户端右键 Update 订阅即可恢复。

### Q21：什么是规则分流（Rule 模式）？
**答**：客户端根据内置规则自动识别：访问国内网站（百度/淘宝）走本地直连网络，访问国外网站（Google/ChatGPT）才走代理，两者互不干扰。

### Q22：什么是 TUN 模式？
**答**：TUN 模式是在操作系统中创建虚拟网卡，强制接管整台设备的所有网络流量，常用于外服游戏加速或让不支持代理设置的命令行工具走代理。

### Q23：第一次选梯子应该注意什么？
**答**：**坚守月付原则！** 首次使用挑选 1~2 家正规老牌服务商购买单月套餐进行实测，确认在本地网络和常用场景下满意后，再考虑长期使用。

### Q24：机场跑路是什么意思？
**答**：指部分资金链断裂或信誉不良的小作坊服务商突然停止维护、关闭网站并失联。防跑路的核心是避免购买超长周期的终身大额套餐，并优先选择运营 2 年以上的老牌平台。

### Q25：ChatGPT 对梯子有什么特殊要求？
**答**：ChatGPT 拥有严格的 IP 欺诈风控体系，需要节点具备原生住宅 IP 属性或纯净机房 IP，避免使用被大量滥用的公共机房黑名单节点。
