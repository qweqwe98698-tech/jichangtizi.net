> **核心结论**：在使用龙猫云（LongMaoCloud）时，**“客户端能看到节点列表甚至测出延迟，并不代表当前网络链路已经畅通”**。有节点仅说明客户端成功读取了本地缓存的配置，并不等于 TCP/TLS 握手成功、系统代理已生效、DNS 解析正常或规则分流无误。
> 
> **第一轮 1 分钟快速自查**：
> 1. **关闭代理测试裸网**：确认本地宽带能正常打开国内百度、B站；
> 2. **右键更新订阅配置**：在 Profiles 中执行 Update 刷新失效的旧节点；
> 3. **跨地区测试 2~3 个节点**：尝试香港、日本或美区节点，排除单点故障；
> 4. **检查系统代理开关**：确认主界面「系统代理 (System Proxy)」处于开启状态；
> 5. **临时切换 Global 测试**：排查是否为 Rule 分流规则异常；
> 6. **排查 TUN 与系统时间**：确认电脑系统时间秒级同步，非必要先关闭 TUN。
> 
> *声明：遇到节点超时或网络异常时请保持理性，切勿盲目恐慌；绝大多数问题均属于本地配置、系统代理或旧订阅缓存冲突，按照本文层级排查即可快速定位修复。*

## 二、技术原理纠偏：为什么客户端里能看到节点，却无法上网？

很多新手最常见的误区是：“我明明在 Clash Verge Rev 或小火箭里看到了香港01、日本01，凭什么说节点不能用？”

必须理清数据链路的 **4 个技术层级**：

```
[步骤 1: 读取本地配置文件] ──> 客户端解析 YAML ➔ 显示节点名称 (仅代表配置存在)
                                    │
[步骤 2: 发起 TCP/TLS 握手] ──> 向节点发送测试小包 ➔ 测出 Ping 延迟 (仅代表握手响应)
                                    │
[步骤 3: 系统代理接管流量] ──> 操作系统将浏览器请求交给客户端 (若未开启系统代理则失效)
                                    │
[步骤 4: 规则分流与 DNS 解析] ─> 判定走代理 ➔ 正确解析海外域名 IP ➔ 成功打开网页
```

- **有节点名称**：只代表你的客户端上周或刚才下载过一份配置文件；
- **能测出延迟**：只代表本地到该节点服务器的单个网络端口响应正常；
- **只有当系统代理开启、规则分流正确、DNS 解析正常、且海外出口机房带宽充沛时，你才能真正打开 Google 与 YouTube**。

## 三、故障症状精准分类诊断表

在动手修复前，请先将自己的症状对号入座，避免盲目折腾：

| 故障症状特征 | 核心潜在故障层级 | 针对性排查方向与第一处理建议 |
| :--- | :--- | :--- |
| **1. 国内和国外所有网站彻底打不开** | 本地裸网断网、或开启了代理但代理完全堵死 | 关闭代理测试裸网，检查家庭路由器或宽带光猫 |
| **2. 微信等国内 App 正常，但所有外网打不开** | 系统代理未生效、所有节点失效、或套餐欠费 | 检查系统代理开关，更新订阅，核对龙猫云后台余额 |
| **3. Google 能正常打开，但 ChatGPT / Claude 报错** | 出口 IP 被海外平台风控拦截，非断网故障 | 切换至 **美国 (US)** 或 **台湾 (TW)** 节点，清理浏览器 Cookie |
| **4. 浏览器正常上网，但 Steam / 命令行 / 软件不走代理**| 该软件不支持系统代理环境变量 | 为终端配置代理端口，或在客户端中开启 **TUN 虚拟网卡** |
| **5. Global 全局模式可用，但 Rule 规则模式无法上网** | 分流规则文件损坏、Rule Provider 下载受阻 | 在 Profiles 中右键重新 Update 完整配置，重置规则集 |
| **6. 不开 TUN 正常上网，一开 TUN 电脑彻底断网** | TUN 虚拟网卡驱动权限不足、与其他 VPN/网卡冲突 | 以管理员身份运行客户端，关闭其他电脑管家与杀毒软件 |
| **7. 手机用 Wi-Fi 能连，切换 5G 移动蜂窝数据断网** | 客户端未获得蜂窝网络权限、或运营商 IPv6 干扰 | 赋予小火箭蜂窝权限，检查 APN 与纯 IPv4 兼容模式 |
| **8. 仅单个节点报红，切换其他节点能正常秒开** | 该特定服务器单机维护或机房重启 | 无需重装软件，直接切换到同地区 02 或 03 节点使用 |
| **9. 订阅列表中所有节点测速全部报红 Timeout** | **电脑系统时间未精准同步**、套餐过期、订阅失效 | **前往系统设置立即同步时间**，登录后台确认套餐状态 |

## 四、本地问题 vs 服务端问题：如何 1 分钟快速定性？

在怀疑服务商之前，通过以下交叉对照表可以瞬间锁定问题发生在哪一端：

| 交叉测试对比方法 | 诊断判断结果 | 结论与处理逻辑 |
| :--- | :--- | :--- |
| **电脑连不上，但用同一订阅的手机连上了** | 🟢 **100% 为电脑本地系统/客户端配置问题** | 重点排查电脑系统代理、防火墙、杀毒软件与本地时间 |
| **手机和电脑连接同一个 Wi-Fi 均无法使用** | 🟡 可能是家庭宽带 DNS 污染，或订阅整体失效 | 手机切换为 4G/5G 蜂窝数据热点再次测试 |
| **手机连 Wi-Fi 失败，切换 5G 热点立刻秒开** | 🟢 **100% 为本地路由器 / 家庭宽带 ISP 路由问题** | 重启家用光猫与路由器，修改路由器 DNS 为 `223.5.5.5` |
| **列表中部分节点报红，但日美等其他节点正常** | 🟢 **属于正常的单节点机房维护** | 直接使用正常的备用节点，等待机房自动恢复 |
| **手机、电脑、热点、全节点多环境持续全部失败** | 🔴 **龙猫云服务端波动、套餐过期或订阅 Token 失效** | 登录官网后台核验套餐状态、查看官方维护公告 |

## 五、10 步系统分层排障与修复全流程

请按照从底层到高层的顺序逐一排查：

### 第 1 步：关闭代理，排查本地裸网连通性
- **操作**：在 Clash Verge Rev 或小火箭中关闭代理；
- **测试**：在浏览器中打开百度、B站或刷新国内应用；
- **判断**：若本地裸网打不开，先解决家庭宽带故障或重启 Wi-Fi 路由器。

---

### 第 2 步：强制更新龙猫云订阅（清除旧节点缓存）
- **操作**：在 Clash Verge Rev 的 Profiles 卡片上右键点击 **「Update (更新)」**；在小火箭主界面向右滑动分组点击 **「更新」**；
- **原理解析**：服务商经常会针对节点服务器进行 IP 轮换或海缆路由割接，客户端中残留的旧节点会全部报红超时，更新订阅能拉取最新可用的服务器 IP 列表。

---

### 第 3 步：跨地区测试 2~3 个不同节点
- **操作**：不要只盯着“香港01”，依次尝试勾选 **香港02、日本01、新加坡01、美国01**；
- **判断**：若日本或美国节点能正常打开网页，说明整体网络与客户端配置完好，仅是特定香港机房处于晚高峰拥塞或短暂维护。

---

### 第 4 步：检查系统代理 (System Proxy) 开关与连接日志
- **操作**：确认 Clash Verge Rev 主界面的 **「系统代理 (System Proxy)」** 开关已处于开启 (ON) 状态；
- **验证技巧**：点击左侧 **「连接 (Connections)」** 菜单，在浏览器中刷新网页。若看到 Connections 面板中有大量的外部网络请求滚动，说明系统代理已成功接管流量；若空空如也，说明系统代理被杀毒软件或浏览器插件拦截。

---

### 第 5 步：检查分流运行模式（Rule vs Global vs Direct）
- **临时测试**：在 Proxies 代理页面顶部，将模式从 **Rule** 临时切换为 **Global (全局代理)** 并测试网页；
- **排查逻辑**：
  - 若 Global 下能打开 Google，但 Rule 下打不开 ➔ 说明节点本身完全正常，是**分流规则集损坏或 Rule Provider 阻断**，在 Profiles 中重新更新配置即可修复；
  - 检查是否误选了 **Direct (直连)** 模式导致所有请求绕过代理。

---

### 第 6 步：检查本地系统时间是否秒级精准同步（90% 超时根源）
- **致命影响**：现代加密协议（TLS / Shadowsocks / Trojan）对时间戳校验极其严格。**本地时间与国际标准时间误差超过 60 秒，会导致所有节点加密握手瞬间被拒绝，全红显示 Timeout**；
- **修复方法**：
  - **Windows**：打开系统「设置」➔「时间和语言」➔ 点击 **「立即同步」**；
  - **iPhone**：打开「设置」➔「通用」➔「日期与时间」➔ 开启 **「自动设置」**。

---

### 第 7 步：排查 DNS 解析链路与 Fake-IP 机制
- **排查原则**：**新手千万不要盲目在配置文件里胡乱添加十几个野生公共 DNS**；
- **科学处理**：若之前自定义过 DNS 设置，先将其恢复为客户端默认配置；
- **Fake-IP 科普**：在连接日志中看到 `198.18.x.x` 地址属于 Mihomo 内核的标准 Fake-IP 机制，并非 DNS 故障或中毒。

---

### 第 8 步：检查 TUN 虚拟网卡模式是否产生冲突
- **排查逻辑**：
  - 如果平时只需用浏览器查资料、看视频，**请先关闭 TUN 模式**，仅保持系统代理；
  - 若开启 TUN 后电脑彻底断网，通常是因为网卡驱动权限不足或与本地安装的 Docker、VMware、Hyper-V 虚拟网卡产生路由冲突；以管理员身份启动客户端并重启电脑通常可解决。
详细 TUN 机制对比参考：[《Clash TUN 模式和系统代理有什么区别？完整指南》](/wiki/clash-tun-mode-vs-system-proxy/)。

---

### 第 9 步：检查客户端与 Mihomo 内核日志报错
打开 Clash Verge Rev 左侧的 **「日志 (Logs)」** 菜单，重点观察以下报错关键词：
- `timeout` ➔ 目标节点响应超时，尝试切换其他国家大区；
- `connection refused` ➔ 目标端口拒绝连接，多为节点维护或旧配置未更新；
- `certificate / TLS error` ➔ 重点校准本地系统时间；
- `authentication error` ➔ 订阅 Token 鉴权失败，需重新获取最新订阅。

---

### 第 10 步：登录龙猫云后台检查套餐与流量余额
- **核验项目**：
  1. 套餐是否已经到达截止日期；
  2. 当月可用流量是否已被大文件下载或后台同步耗尽；
  3. 订阅 Token 是否被系统自动重置；
  4. 是否超出了套餐允许的同时在线设备数上限。

## 七、常见操作系统专属排障技巧

### 1. Windows 电脑专属排查
- **清理旧代理残留**：进入 Windows「设置」➔「网络和 Internet」➔「代理」，确认未勾选其他未知手动代理脚本；
- **关闭第三方安全软件拦截**：暂时退出 360 安全卫士、腾讯电脑管家等可能拦截系统代理端口的安全软件。

### 2. macOS 苹果电脑专属排查
- **系统代理权限授权**：在 macOS「系统设置」➔「网络」中确认 Clash Verge Rev 已获得配置系统代理的网络权限；
- **M 芯片兼容性**：确保下载的是对应 Apple Silicon (arm64) 架构的安装包。

### 3. iPhone / iPad 小火箭专属排查
- **蜂窝网络权限**：进入 iPhone「设置」➔「蜂窝网络」➔ 确认给 Shadowrocket 勾选了「无线局域网与蜂窝数据」；
- **重置 VPN 配置**：在小火箭中若持续无法连接，可在系统设置中删除小火箭的 VPN 配置，随后在 App 内重新开启开关并允许添加。
详细教程参考：[《龙猫云怎么导入 Shadowrocket？iPhone 小火箭订阅教程》](/tutorials/shadowrocket/longmao-cloud/)。

## 十、什么时候才应该真正考虑准备备用机场？

我们必须保持客观克制：**“偶尔单节点维护或晚高峰波动，绝不等于服务商跑路。”**

### 只有在出现以下情况时，才建议启用备用方案：
1. 多个地区的所有节点持续数小时全红超时，且官方未给出维护说明；
2. 官网与后台持续无法解析，且订阅接口长期返回 500 或 404；
3. 本地网络与多设备交叉验证均完全正常，但代理服务持续无法使用。

> 💡 **防断网最佳实践**：日常建议在客户端中常备一个由不同服务商提供的小额按量流量包作为“第二备用通道”，在主力机场维护时提供可靠的应急连接。

## 十一、高频常见问题解答（FAQ）

### Q1：龙猫云有节点但打不开网页是什么原因？
**答**：最常见的原因是主界面的“系统代理 (System Proxy)”开关未开启，或者电脑本地系统时间存在偏差导致加密握手失败。另外，旧订阅缓存未更新、套餐欠费也会导致此现象。

### Q2：龙猫云所有节点都显示 Timeout 超时怎么办？
**答**：首先前往系统设置**立即同步系统时间**；随后登录龙猫云后台确认套餐有剩余流量；最后在 Profiles 页面右键 Update 更新订阅获取最新节点 IP。

### Q3：为什么换了一个节点就能上网，原来的节点不行？
**答**：说明龙猫云服务与你的本地客户端完全正常，只是原来的单个节点服务器正在进行机房维护或临时网络割接。直接使用正常节点即可，无需重装软件。

### Q4：为什么 Global 全局模式能用，Rule 规则模式不能用？
**答**：说明节点本身连接畅通，但分流规则配置文件损坏或未能正确识别海外域名。在 Profiles 中右键重新 Update 更新完整订阅即可修复规则集。

### Q5：为什么平时好好的，一开 TUN 模式就彻底没网？
**答**：TUN 虚拟网卡需要较高的系统管理员权限，且容易与杀毒软件、其他 VPN 或虚拟机网卡产生路由表冲突。日常办公只需开系统代理即可，非游戏需求建议关闭 TUN。

### Q6：手机连家里 Wi-Fi 不能用，但开 4G/5G 热点就能用是为什么？
**答**：这 100% 是家庭路由器或宽带运营商的问题（如路由器 DNS 污染或特定海缆路由波动）。尝试重启家用光猫与路由器，并将路由器 DNS 手动改为 `223.5.5.5`。

### Q7：Google 能正常秒开，为什么 ChatGPT 提示 Access Denied？
**答**：这不是断网问题，而是该节点的出口 IP 触发了 OpenAI 的安全风控。在节点列表中手动切换至 **美国 (US)** 或 **台湾 (TW)** 节点即可正常访问。

### Q8：龙猫云节点全部超时是不是跑路了？
**答**：不要盲目恐慌。90% 的全红超时是因为本地时间未同步或节点列表过旧。先同步时间并更新订阅，若手机热点与其他设备也全部无法使用，再登录官网后台查看是否有重大机房升级公告。

## 总结与系统排障方法论

> **科学排障 4 大铁律**：
> 
> 1. **先裸网后代理** ➔ 本地网络畅通是排查一切代理故障的前提；
> 2. **逢异常先更订阅** ➔ 遇到批量超时，右键 Update 订阅能解决 80% 的节点过期问题；
> 3. **分清系统代理与 TUN** ➔ 日常网页办公认准系统代理，避免盲目开 TUN 制造网络冲突；
> 4. **多端交叉验证** ➔ 手机电脑双测，秒级定位是单机问题还是服务端波动！
