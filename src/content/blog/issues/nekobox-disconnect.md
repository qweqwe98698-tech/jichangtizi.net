## 二、第一大真相：锁屏掉线的幕后黑手（Doze 与电池优化）

很多用户误以为“锁屏断网是 NekoBox 的 Bug”，实际上这是 Android 系统的电源管理在起作用：

```mermaid
graph TD
    ScreenOff[用户按下电源键 ➔ 手机锁屏息屏] --> Timer[静置 3~5 分钟进入待机状态]
    Timer --> AndroidDoze[Android 系统激活 Doze 深度休眠与 App Standby]
    
    AndroidDoze --> RestrictNet[1. 冻结所有未加白名单的后台网络访问]
    AndroidDoze --> RestrictCPU[2. 限制后台 CPU 唤醒锁 (WakeLocks)]
    AndroidDoze --> KillProcess[3. 内存吃紧时优先回收后台 GUI 进程]
    
    RestrictNet --> DropSession[底层 Proxy 长连接因缺乏心跳被 NAT 网关单向丢弃 ➔ 发生断流]
```

### 1. 深度澄清：三大省电机制的本质区别
- **电池优化（Battery Optimization）**：系统控制后台应用电量消耗的基础机制。若未设为“无限制”，后台网络权限会被随时剥夺；
- **Doze 深度休眠**：设备熄屏且静止一段时间后，系统强行推迟后台任务与网络访问，直到进入短暂的“维护窗口（Maintenance Window）”；
- **省电模式（Battery Saver）**：用户手动或低电量自动触发的全局降频机制，会更激进地限制后台网络。

## 三、第二大真相：Wi-Fi 与 5G 切换为什么会导致断流？

从 Wi-Fi 走到室外切换到 5G 手机网络后，网络底层发生了翻天覆地的物理变化：

```mermaid
graph TD
    WiFiState[Wi-Fi 状态: IP 为 192.168.1.5 ➔ 家用路由器 NAT 映射] --> Switch[用户离开 Wi-Fi 覆盖区 ➔ 切换至 5G 蜂窝网络]
    
    Switch --> NewInterface[Android 系统切换默认网络接口至 rmnet_data]
    NewInterface --> NewIP[运营商分配全新的 5G 移动蜂窝 IP ➔ 运营商级 CGNAT]
    
    NewIP --> SocketBroken[旧的 TCP/WebSocket 套接字因源 IP 改变瞬间失效 (Broken Socket)]
    SocketBroken --> CheckReconnect{NekoBox 与目标 App 的恢复流程}
    
    CheckReconnect --> Step1[1. NekoBox Core 捕获网络变化事件 ➔ 重新向节点服务器发起 Dial]
    CheckReconnect --> Step2[2. 代理隧道重新建立就绪]
    CheckReconnect --> Step3[3. 目标 App (如 Telegram) 重建自身长连接 ➔ 恢复通信]
```

- 💡 **关键排查认知**：切网后如果状态栏钥匙图标在但网页打不开，通常是底层代理正在重新建立握手，或 Telegram 等目标应用尚未刷新旧连接。**此时重开一次目标 App 即可秒级恢复！**

## 五、深度排障：四级稳定性阶梯测试法

排查掉线时，请按照由易到难的**四级稳定性阶梯**进行受控测试：

1. **第一级：前台亮屏测试（15 分钟）** ➔ 屏幕常亮且停留在 NekoBox 界面，持续浏览网页。若此时依然掉线，说明是**节点服务器或线路本身不稳定**，而非系统杀后台；
2. **第二级：切后台亮屏测试（15 分钟）** ➔ NekoBox 切到后台，前台使用其他 App。若此时掉线，说明**缺少前台服务常驻通知或内存被回收**；
3. **第三级：锁屏熄屏测试（30~60 分钟）** ➔ 手机锁屏静置。若唤醒后发现断网，重点排查 **Doze 深度休眠与电池无限制设置**；
4. **第四级：切网自愈测试（瞬时）** ➔ 在连接状态下手动关闭 Wi-Fi 切换到 5G，观察 5~10 秒内能否自动重连并恢复网页浏览。

❌ 误区 11：在地铁或地下车库掉线，说明节点服务商正在进行恶意的定时限速 ➔ 事实：这是移动蜂窝网络基站弱信号与基站切换导致的物理丢包断流。
❌ 误区 12：无论什么原因导致的掉线，只要把 NekoBox 里的 DNS 换成 8.8.8.8 就能解决 ➔ 事实：DNS 仅负责域名解析，无法改变 Android 系统的进程调度与保活机制。
❌ 误区 13：只要开启了 Android 系统的“始终开启的 VPN”，节点就永远不可能掉线 ➔ 事实：该功能仅在断开时阻止裸网通信，节点服务器宕机时依然会断。
❌ 误区 14：NekoBox 每次掉线后，必须把手机完全关机重启才能重新恢复网络 ➔ 事实：通常只需在 NekoBox 界面点击断开并重新连接一次即可刷新隧道。
❌ 误区 15：晚高峰 21:00 频繁出现断线重连，说明当前使用的手机硬件已经老化 ➔ 事实：晚高峰公网骨干网丢包激增触发了 TCP 超时重传失败，核心在专线质量。

## 八、常见问题深度解答（FAQ · 100 问）

### Q1：NekoBox 为什么手机一锁屏息屏就自动断开？
**答**：**根源在于 Android Doze 低功耗休眠限制了后台网络。** 进入手机【设置】➔【应用管理】➔ 找到 NekoBox ➔【电池】选【无限制】并在多任务界面锁定后台卡片。

### Q2：切出 NekoBox 界面后，状态栏钥匙图标立刻消失怎么办？
**答**：**说明 NekoBox 的前台服务被系统直接杀死。** 确保 NekoBox 的通知权限已开启（允许常驻通知栏），并在系统中授予自启动权限。

### Q3：为什么从家里 Wi-Fi 切换到 5G 手机网络后，外网会断流？
**答**：**网络接口切换导致手机源 IP 改变，旧 TCP 会话全部失效。** 在 NekoBox 中点击断开并重新连接一次，或重新打开目标 App 即可刷新长连接。

### Q4：为什么钥匙图标还在，但 Telegram 和微信却收不到任何消息？
**答**：**钥匙图标仅代表本地网卡激活，底层 TCP 会话可能已被 NAT 丢弃。** 进入 NekoBox 查看日志，若有超时报错说明节点服务器已断流，建议切换节点。

### Q5：小米 / HyperOS 手机该如何防止 NekoBox 锁屏被杀？
**答**：长按 NekoBox 图标 ➔【应用信息】➔【省电策略】改为【无限制】；开启【自启动】；在后台多任务卡片上下拉加锁。

### Q6：华为 / HarmonyOS 手机该如何配置保活？
**答**：进入【设置】➔【应用和服务】➔【应用启动管理】➔ 找到 NekoBox ➔ 关闭【自动管理】，手动开启【允许自启动】与【允许后台活动】。

### Q7：三星 / One UI 手机锁屏断线怎么解决？
**答**：进入【设置】➔【应用程序】➔ NekoBox ➔【电池】选【不受限制】；并在【设备照顾】中将 NekoBox 加入【从不休眠的应用】名单。

### Q8：为什么晚上睡觉前连着好好的，早晨醒来必定掉线？
**答**：**长时间静置触发了系统最深层的 App Standby 极度休眠。** 确保电池无限制配置生效，并排查路由器是否存在半夜定时重启或 Wi-Fi 睡眠策略。

### Q9：频繁掉线时，怎么判断是手机系统杀后台还是节点本身断流？
**答**：**进行 15 分钟亮屏前台测试。** 若手机一直亮屏使用仍然频繁掉线，说明是节点或线路问题；若只有锁屏后掉线，则 100% 是系统省电策略所致。

### Q10：遇到 NekoBox 经常掉线，排查的第一步到底应该做什么？
**答**：**第一步必须确认掉线发生的具体时机。** 区分是锁屏掉线、切后台掉线、切 Wi-Fi/5G 掉线还是定时掉线，切忌盲目乱改设置！

### Q11：掉线问题解决后，怎样配置 NekoBox 的 DNS 与域名解析才最稳定？
**答**：建议接下来关注本站即将推出的《NekoBox DNS怎么设置？Private DNS、IPv6、FakeIP与域名解析完整指南》，系统攻坚 DNS 深度调优。

排查 NekoBox 经常掉线，请牢记以下**核心铁律**：

```text
1. 辨时机 ➔ 区分是锁屏掉线、切后台掉线、切网掉线还是前台定时断流
2. 调电池 ➔ 针对锁屏掉线，优先配置系统【电池无限制】并锁定后台任务卡片
3. 保前台 ➔ 确保 NekoBox 常驻通知栏权限开启，防止前台服务被系统内存回收
4. 懂切网 ➔ Wi-Fi 与 5G 切换会导致源 IP 改变，必要时手动重连刷新会话
5. 选专线 ➔ 晚高峰频繁断流重连的终极解法是依靠物理隔离的 IEPL 企业级内网专线
```
